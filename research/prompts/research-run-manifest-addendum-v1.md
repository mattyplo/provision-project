## Additional deliverable: draft research-run manifest

Alongside the research report, return a **draft** using the provided research-run manifest template. Populate only fields you can observe or that the operator explicitly supplies. Record inaccessible sources and research limitations. Distinguish **agent-reported**, **operator-provided**, and **not available** metadata.

Do **not** invent model identifiers, Git commit SHAs, exact submitted prompt text, file paths, execution timestamps, or platform settings. Mark unavailable details `Not recorded` or `Not exposed`.

The draft is not the authoritative execution log. The operator or orchestration environment must preserve the **complete verbatim submitted prompt** (including this addendum), original unedited output, and externally observed settings/timestamps, then reconcile the draft manifest. Do not claim to have written repository files unless you actually did.

The research findings and citations remain subject to a separate source audit.
